# Company Autonomous Work Cycle

L4.2 defines a mission-bounded autonomous work cycle simulator for the company
agent team.

The simulator shows how the company can move from founder mission to observation,
work proposal, role delegation, governed tool selection, Pre-U simulation,
governance decision simulation, simulated action planning, dry-run CIEU event
shape, residual delta, and next-task recommendations.

It is not live execution. It does not call external services, create issues,
push code, control daemons, persist CIEU, write brain/memory, or ingest raw
runtime artifacts.
