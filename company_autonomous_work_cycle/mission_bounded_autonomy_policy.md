# Mission-Bounded Autonomy Policy

The founder sets the mission, constraints, and priorities. The agent team may
then simulate self-directed work cycles against generated read-model evidence.

Allowed in this pack:

- Read curated generated summaries.
- Propose mission-relevant work.
- Delegate responsibilities to role agents.
- Select disabled governed tool candidates.
- Simulate Pre-U, governance, CIEU, residual, and next-task artifacts.

Forbidden in this pack:

- Real action execution.
- External communication or network calls.
- Git push or GitHub issue/PR creation.
- CIEU persistence.
- Brain or memory writeback.
- Candidate approval or semantic truth scoring.
