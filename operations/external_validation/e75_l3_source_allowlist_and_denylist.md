# E75 L3 Source Allowlist And Denylist

- Status: proposed_for_owner_approval_not_executed

## Allowed Source Categories
- official_agent_framework_docs: Official docs from AI agent frameworks and tool ecosystems
- ai_governance_observability_security_vendor_pages: Public product pages from adjacent AI governance, agent observability, security, and audit vendors
- ai_infrastructure_public_blogs: Public blog posts from AI infrastructure companies
- public_github_repos_issues: Public GitHub repos and issue discussions where no login is required
- public_standards_regulatory_guidance: Public standards/regulatory guidance pages
- public_founder_operator_discussions: Public founder/operator discussions accessible without login
- public_job_posts: Public job posts
- public_pricing_pages: Public pricing pages from adjacent products
- public_conference_talks_transcripts: Public conference talks/transcripts accessible without login
- public_vendor_case_studies: Public case studies from vendors

## Denylisted Source Categories
- private communities
- login-gated pages
- paid databases or paid reports
- personal social profiles for outreach
- customer contact lists
- scraped emails, phone numbers, or handles
- anything requiring account creation
- anything requiring API keys or credentials
- anything that triggers posting, messaging, forms, transactions, or terms acceptance on behalf of owner

## Allowed Future L3 Actions
- read public pages
- read public documentation
- read public market pages
- read public competitor/product pages
- read public community discussions only if no login is required
- record citations and receipts
- summarize evidence
- map evidence to buyer/problem/product assumptions

## Denied Future L3 Actions
- contacting customers
- contacting experts
- sending emails or messages
- submitting forms
- posting comments
- joining communities
- scraping behind login
- accepting terms on behalf of owner
- payment actions
- creating accounts
- API calls requiring credentials
- publication
- advertising
- claiming customer validation
- claiming paid signal
- claiming compliance/legal proof
- claiming production readiness
