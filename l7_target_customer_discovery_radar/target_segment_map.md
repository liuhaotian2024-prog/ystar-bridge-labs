# Target Segment Map

- AI startup founder: urgent AI workflow choice, needs investor/customer-ready clarity, founder time bottleneck
- technical operator: owns internal AI tooling, needs workflow governance, wants low-risk automation
- solo founder building with AI agents: uses coding agents, needs one-person operating leverage, needs decision support
- small AI automation agency owner: client delivery quality risk, needs audit templates, needs proof package
- founder using Codex/Claude Code/OpenClaw-like workflows: agent governance uncertainty, toolchain sprawl, approval boundary confusion
- startup team with urgent strategy/research/workflow decision: fast research needed, unclear automation ROI, needs internal command brief
