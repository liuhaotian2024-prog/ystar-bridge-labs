# Retry Runtime Guard

L6.10R CONTROLLED SOURCE LOCATOR RESOLUTION AND TINY OBSERVATION RETRY.

The guard keeps the retry at one work order, one locator, one page/source, and no disallowed actions.

This artifact does not authorize broad search, repeated search loops, crawling, scraping, browser automation, login, account creation, payment, form submission, posting/commenting/messaging, publication, outreach, revenue execution, MCP execution, live behavior, CIEU DB write, canonical mutation, brain/memory writeback, or direct Y* mutation.
