# E18 Offer Variant Matrix

- lead_offer: 48h AI Agent Implementation Readiness Review
- experiment_policy: small_manual_send_owner_approved_variants_only
- external_action_executed: false

## direct_readiness_review
- target_condition: Target already shows AI-agent readiness or governance interest.
- message_angle: 48h readiness scorecard and safe next step.
- CTA: Would this be useful enough to consider a paid diagnostic or pilot-prep conversation?
- risk_notes: Avoid implementation promises; keep diagnostic-only.
- when_not_to_use: If target lacks agent/readiness evidence.

## risk_reduction_framing
- target_condition: Target language mentions governance, compliance, safety, review gates, or operational risk.
- message_angle: Reduce implementation risk before agent workflows move into real operations.
- CTA: Would a short risk/readiness review help de-risk the next AI-agent implementation decision?
- risk_notes: Do not imply legal/compliance advice.
- when_not_to_use: If target only wants growth/marketing automation.

## implementation_bottleneck_framing
- target_condition: Target likely faces workflow bottlenecks, deployment friction, or client implementation uncertainty.
- message_angle: Find the blocker and the smallest safe operational next step.
- CTA: Would mapping the main AI-agent implementation blocker in 48h be worth a diagnostic conversation?
- risk_notes: Do not promise to fix production systems.
- when_not_to_use: If no workflow or implementation pain evidence exists.

## founder_operator_pain_framing
- target_condition: Founder/operator target with unclear owner decision or resource constraints.
- message_angle: Reduce decision load and clarify whether the next AI-agent step is worth doing.
- CTA: Would a compact readiness review help decide whether to invest in this agent workflow now?
- risk_notes: Avoid pretending to know internal priorities.
- when_not_to_use: If target is a mature enterprise with formal procurement language only.

## lightweight_advisory_framing
- target_condition: Agency/consulting target that may need a pre-implementation artifact for clients.
- message_angle: A lightweight client-facing readiness artifact before deeper implementation work.
- CTA: Would this be useful as a paid pre-implementation diagnostic for your AI-agent clients?
- risk_notes: Do not suggest a partnership exists.
- when_not_to_use: If target is not agency/consulting/operator-facing.
