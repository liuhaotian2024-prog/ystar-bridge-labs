# E41 Frontier Capability Import Loop

- loop stages: 12
- Loop is a permanent method inside existing CEO brain.

## Stages

- stage: 1, name: detect CEO weakness, required_output: gap statement with source artifact evidence
- stage: 2, name: search frontier external capability, required_output: public read-only source references only
- stage: 3, name: classify source quality, required_output: source type, maturity, risk, freshness
- stage: 4, name: map to internal capability gap, required_output: target gap and target repo classification
- stage: 5, name: choose import pattern, required_output: method-only/schema/evaluator/artifact builder/future tool/Y-star-gov proposal/gov-mcp proposal/future repo/reject
- stage: 6, name: no-rebuild check, required_output: prove no duplicate kernel, MCP layer, CIEU, CZL, route registry, CEO brain, or CEO KG
- stage: 7, name: cross-repo ownership check, required_output: bridge-labs vs Y-star-gov vs gov-mcp ownership map
- stage: 8, name: evidence boundary check, required_output: not validation, not paid signal, not canonical learning unless approved
- stage: 9, name: implementation plan, required_output: files, tests, forbidden side effects
- stage: 10, name: test requirement, required_output: targeted tests and relevant prior tests
- stage: 11, name: owner approval requirement, required_output: whether any future external action or repo change needs owner approval
- stage: 12, name: post-import capability evaluation, required_output: compare before/after CEO decision quality
