# Work Proposal Policy

- Work proposals must originate from generated/read-model mission and
  observation evidence.
- The agent team may propose, score, select, and review work only as a dry-run
  planning artifact.
- Tool invocation must route through the governed Pre-U bridge; direct
  agent-to-tool invocation is forbidden.
- Live action, external communication, GitHub issue/PR creation, git push,
  daemon control, CIEU persistence, brain writeback, and memory ingestion remain
  disabled.
- Generated CIEU-style events are fixtures only and require curation before any
  future learning path.
