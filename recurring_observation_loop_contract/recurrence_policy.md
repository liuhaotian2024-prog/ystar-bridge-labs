# Recurrence Policy

The recurring observation loop is defined but disabled.

Allowed now:
- Build the recurrence contract.
- Simulate one manual local observation tick.
- Read curated generated/read-model JSON summaries.
- Emit generated dry-run artifacts under this pack.

Forbidden now:
- Scheduler activation.
- Daemon activation.
- Automatic recurring execution.
- External observation or communication.
- Live action, CIEU persistence, brain writeback, or memory ingestion.

Future enablement requires operator review, governance gate review, source registry review, stop/abort policy review, escalation policy review, and a scheduler sandbox design.
