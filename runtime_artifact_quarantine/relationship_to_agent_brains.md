# Relationship to Agent Brains

`agent_brains/` contains persistent role-brain read models.

Runtime artifacts may nourish brains only after curation. CIEU, dream, and
writeback flows must be evidence-backed.

Aiden, Ethan, and Samantha should not ingest raw artifacts directly. Ethan
execution channels may produce artifacts, but tool logs are not Ethan memory by
default.

Future brain writeback should consume curated memory candidates, not raw DBs,
logs, markers, or daemon state.
