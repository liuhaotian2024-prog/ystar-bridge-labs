# CIEU Nutrition

CIEU remains evidence first. The capsule treats CIEU as nutrition only because existing artifacts already define CIEU-to-brain flows.

## Roles of CIEU

- Evidence: CIEU records what happened, who acted, target/result context, decisions, and governance outcomes.
- Residual signal: CZL and Amendment 014 treat residual as the indicator that a loop is closed or still open.
- Memory nutrition: CIEU outcomes provide structured experience that can influence future recall and learning.
- Brain writeback input: L2 designs use post-action outcomes to update activation/access/edge strength.
- Dream replay input: L3 dream scans activation history and CIEU-derived activations to propose consolidation changes.
- Governance insight input: Board/CEO insights can enter both memory and rules, per the dual-aspect governance ruling.
