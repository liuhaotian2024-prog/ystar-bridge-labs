# Agent Brain Capsule

Agent Brain Capsule is not a new theory.

It is a runtime-facing wrapper around existing Y* cognitive, CZL, field, brain, memory, and governance assets that already exist in the local workspace. This directory does not replace those artifacts, copy their contents, or migrate DB state. It gives future readers and runtime-facing tools a stable map from "what the agent is" to "how the agent learns and closes loops."

The capsule goal is to connect the prior wheels:

- DNA and ontology: identity, operating principles, Board relationship, and role memory.
- Memory: long-term references, working state, boot packages, and session handoff.
- Thinking model: counterfactual operating style plus the 6D cognitive substrate.
- Mission field: Y* as a mission functor field with deterministic `m_functor` validation.
- CZL: task-level residual closure via `Y* / Xt / U / Yt+1 / Rt+1`.
- CIEU nutrition: CIEU as evidence, residual signal, brain activation source, and dream replay input.
- Writeback and dream: L2 post-action learning and L3 offline consolidation.
- Governance boundary: deterministic kernel checks remain separate from cognitive/operational achievement.

This layer is intentionally reference-only. The source of truth remains in the indexed artifacts.
