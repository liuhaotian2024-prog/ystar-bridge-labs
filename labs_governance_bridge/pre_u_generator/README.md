# Pre-U Generator

The Pre-U generator creates dry-run counterfactual packets for curated labs
task envelopes and role-brain capsule references.

The generator covers the current role-brain capsules:

- Aiden-CEO
- Ethan-CTO
- Samantha-Secretary

It produces generated Pre-U packets, converts them to Y-star-gov-compatible
hook envelopes, and lets the dry-run bridge call the Y-star-gov hook contract
CLI for deterministic structure judgment.

This is not runtime execution. Generated packets are not actions, CIEU records,
memory updates, brain writebacks, candidate approvals, or semantic truth claims.
