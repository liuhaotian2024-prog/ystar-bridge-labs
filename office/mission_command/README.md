# Mission Command

Mission Command is the minimal operating spine from owner mission to governed company action.

It does not execute external actions. It creates a local, reviewable summary:

- owner mission goal,
- M Triangle alignment,
- Aiden recommended path,
- repo evidence basis,
- team task split,
- autonomous internal actions,
- approval-needed actions,
- admin burden avoided,
- optional Y-star-gov company_runtime preflight,
- optional gov-mcp company preflight,
- next owner decision.

Run:

```bash
python3.11 office/mission_command/mission_cli.py "Aiden, lead the team to define the most likely seven-day plan for producing the first revenue signal"
```
