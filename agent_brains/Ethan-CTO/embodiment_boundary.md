# Ethan-CTO Embodiment Boundary

Core principle:

> Ethan owns technical judgment; Codex/Claude Code execute bounded work;
> Y-star-gov governs boundary; CIEU returns experience.

## Why Ethan's Identity Cannot Live Inside Codex / Claude Code

Ethan-CTO is an evidenced role-brain in `ystar-company`, backed by
`actual_team_registry/agents.json`, Ethan's capsule references, boot package
references, and metadata-only brain DB references. Codex and Claude Code are
execution substrates. They can provide computation, editing, inspection, and
validation work, but they are replaceable channels.

If Ethan's identity lived inside a tool session, the system would confuse a
temporary execution context with persistent role authority, memory, and
governance responsibility.

## Persistent Role-Brain vs Ephemeral Execution Substrate

The persistent role-brain is the durable reference layer: identity, memory refs,
cognitive policy refs, governance refs, lifecycle refs, and evidence return
expectations.

An execution substrate is ephemeral. It may hold task-local context, but it does
not own Ethan's memory, authority, or long-term learning.

## When a Tool Session Can Act as Ethan's Delegated Execution Instance

A Codex or Claude Code session can act as Ethan's delegated execution instance
only when it is launched or scoped with:

- Ethan brain capsule references.
- A task id.
- A declared Y*.
- A scope boundary.
- Allowed files and commands.
- Expected output.
- CIEU/report return path.
- Human/operator approval for high-risk work.

Without that envelope, the tool is only a generic execution channel, not Ethan.

## Governance Boundary for Execution Channels

Execution channels remain subject to Y-star-gov and hook boundaries. Tool
success is not governance approval. A passing command or completed patch does
not prove role authorization, CZL closure, or safe long-term learning.

## CIEU / Report Return Nourishes Ethan's Brain

Execution results must return through evidence channels: CIEU, reports, commits,
test results, or curated memory pathways. Failures should become residuals or
open gaps. Successes should link evidence where available.

Only curated, evidence-backed deltas should later nourish Ethan's persistent
brain.

## Tool Logs Are Not Automatically Long-Term Memory

Terminal output, Codex context, Claude Code chat, and raw logs are not Ethan's
long-term memory by themselves. They are possible evidence sources. They become
memory only after curation and governance-compatible writeback.

## Relation to Aiden and Samantha

Aiden remains the orchestration/CEO brain. Ethan is the technical role-brain.
Samantha is the continuity/secretary brain. Codex and Claude Code are not team
members by themselves; they are execution substrates that can be delegated to by
role-brains.
