# Brain Learning Contract

Aiden's brain should not learn directly from a speculative Pre-U packet alone.

Future learning should use:

- The packet prediction.
- The selected action.
- The actual outcome.
- The actual residual.
- The CIEU predicted-vs-actual delta.
- Governance/intervention signals if present.

## L2 Writeback

L2 writeback should use actual outcome-weighted signal. A prediction that looked
good before action should not become durable learning unless CIEU confirms the
outcome and residual behavior.

## L3 Dream

L3 dream should replay repeated patterns, failures, surprising residuals, and
missed counterfactuals. Dream replay should remain guarded by existing brain
lifecycle and governance references.

## Field Drift

If predicted residual repeatedly diverges from actual residual, that may indicate
field drift, weak m_functor grounding, missing evidence, or a flawed cognitive
policy. The learning signal should preserve that distinction rather than
collapsing every miss into a generic memory update.

## Governance Insight

A governance insight can become a rule candidate only after evidence. Imagination
alone is not sufficient. Packet predictions can propose hypotheses; CIEU deltas
and repeated evidence decide whether a governance rule should be considered.

DB contents were not inspected and are not modified by this contract.
